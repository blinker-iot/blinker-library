# ESP32-S3 界面配置例程

用于本地 Web App 读取设备能力并生成界面。Manifest 由 Blinker 库根据声明生成，固件不包含 App 布局或设备专属判断。

| 字段 | 类型/权限 | 行为 |
|---|---|---|
| demoPower | 布尔，可写 | RAM 演示开关，不驱动 GPIO |
| demoBrightness | 整数 0–100%，可写 | RAM 演示亮度 |
| demoLabel | 文本，最多 24 字节，可写 | 保存并回报文本 |
| buttonPresses | 整数，只读 | 动作累计次数 |
| pressButton | 动作 | 计数加一 |
| wifiRssi | 整数，只读，dBm | 实际 Wi-Fi 信号强度 |
| uptimeSeconds | 整数，只读 | 实际开机秒数 |
| freeHeapBytes | 整数，只读 | 实际剩余堆内存 |

演示状态重启后恢复默认值。运行指标每 5 秒更新，Wi-Fi 未连接时不伪造信号强度。

## 本地配置

复制 secrets.example.h 为 secrets.h，填写 Wi-Fi 和目标设备 DeviceKey。secrets.h 已被 Git 忽略；固件二进制包含凭据，不应公开分发。

编译使用本机 Aily 工具链：ESP32 core 3.3.1、esp-x32 14.2.0、Arduino libs 5.5.0、PubSubClient v2.8。

首次准备 PubSubClient（在仓库根目录）：

```sh
mkdir -p .build/libraries

git clone --depth 1 --branch v2.8 https://github.com/knolleary/pubsubclient.git .build/libraries/PubSubClient
```

在仓库根目录编译：

```sh
./examples/Esp32S3InterfaceDemo/build.sh 192.168.1.108
```

默认 SDK 路径为本机 Library/aily-project，可通过 AILY_PROJECT_DIR 覆盖。宏必须应用到全部库编译单元，不能只在 ino 中定义 Gateway 地址。

## 网络与烧录

- Gateway HTTP：Mac 局域网地址的 17000 端口。
- Gateway 返回给设备的 MQTT：同一局域网地址的 8883 端口。
- ESP32 与 Mac 必须网络互通；地址变化后更新后端 GATEWAY_PUBLIC_HOST 并重新编译。
- 当前编译采用WiFiduino32S3 对应的通用 ESP32-S3、16 MB Flash、禁用 PSRAM、UART 串口；实际烧录前必须确认芯片和 Flash 容量。
- 不执行整片擦除，保留 NVS；烧录时分别使用构建产物及实际分区偏移，不直接用 merged.bin 覆盖已有存储。
- 串口 115200，发送 d 可输出库诊断。不要将凭据打印到串口。

编译成功不代表烧录成功。应先确认设备在线与 Manifest，再在 App 中识别设备并执行 AI 生成。
